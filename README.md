## 在澳洲租过房的人，谁没被扣过押金？

清洁费、地毯污渍、草坪维护、墙上的钉眼……退租时房东开出一张扣款清单，你明明觉得不合理，却不知道法律怎么说、信该怎么写、该找哪个部门。多数人最后选择认栽。

**BondBack 押金侠**面向 NSW 和 VIC 的租客，把「查法条 → 评估胜算 → 写维权信 → 走流程」压缩成一次 30 秒的向导式体验——全程中文操作，产出正式英文信件。

## 它怎么帮你

1. **三步向导**：选州 → 纠纷类型 → 关键数字，像报税一样简单，不用跟机器人聊天
2. **拍照上传，AI 自动识别**：房间照片、租约 PDF、入住 condition report、聊天截图——AI 自动提取押金金额等关键信息，表单自己填好
3. **AI 逐项审查，输出三件套**：
   - 🎯 **胜算评估卡**：每笔扣款 ✅合法 / ❌不合法 / ⚠️存疑，附具体法条编号
   - ✉️ **正式英文维权信**：可编辑、可下载 PDF，附中文对照解释
   - 🗺️ **行动路线图**：Fair Trading / Consumer Affairs → NCAT / VCAT 完整路径、费用、时限，还有邮件留证话术模板
4. **押金存管核实** 🚨：结合付款对象、日期、官方查询结果和各州期限，区分“需要核实”与“可能未按期存管”；不会仅因没收到邮件就指控房东违法

## 为什么可信

- **诚实评估**：不是所有扣款都能争。房东占理的项目（比如拖欠租金抵扣），AI 会直接告诉你「合法，别争」——不给你虚假希望
- **法条来自官方**：NSW Fair Trading、Consumer Affairs Victoria、RTBA、NCAT/VCAT 等官方来源，逐条核实、附原文引用
- **不收集你的数据**：无需注册登录，没有数据库，分析在会话内完成即走

## 先看个案例 👀

不想立刻上传自己的材料？首页有一个根据真实案例改编的完整示例：押金 $3,560、被索扣 ~$800，看 AI 如何逐项反杀三笔不合理扣款、并诚实认定一笔合法扣款。

## 技术栈

- Next.js（App Router）+ TypeScript + Tailwind CSS，部署于 Vercel
- OpenAI 双模型：gpt-4o-mini 负责证据识别与字段提取，强模型负责法律分析与信件生成
- 州法规以结构化数据直接注入上下文，保证引用稳定准确
