# BondBack · 押金侠

> **房东乱扣 Bond？先别认栽。**
> 上传扣款清单和入住报告，AI 按 NSW/VIC 租赁法规逐项比对证据，告诉你哪几笔不应扣、凭哪条法规，并生成一封可直接发送的英文申诉信。

## 在澳洲租过房的人，谁没被扣过押金？

清洁费、地毯蒸洗、草坪维护、说不清的水电尾数……退租时房东开出一张扣款清单，你明明觉得不合理，却不知道法律怎么说、信该怎么写、该找哪个部门。多数人最后选择认栽。

**BondBack 押金侠**面向 NSW 和 VIC 的租客——它不是一个法律问答机器人，也不是一个套模板的写信工具，而是**把你的证据、你的合同和州租赁法逐项对上**的维权闭环。全程中文操作，产出正式英文信件。

## 三层 AI 能力

**① 从你的材料里提取事实**
入住 condition report、租约 PDF、房间照片、与中介的聊天截图、扣款清单——AI 逐份读完，抽出带定位和原文引语的事实（「入住报告 P3 客厅：`Carpet: existing stains noted`」）。

**② 把每笔扣款和证据、合同、法条对上** ← 产品的核心
每一笔扣款都会经过三轴审查——损伤是否**原已存在**、合同**是否真有此义务**、是否属**合理磨损**——并给出可点回原件的证据引用与具体法条编号。

```
① 退租专业清洁 + 地毯蒸洗   $780        ❌ 不合法
   证据  入住报告 P3 · 客厅地毯 "Carpet: existing stains noted"
   合同  笼统的专业洗地毯条款可能无效
   法条  Residential Tenancies Act 2010 (NSW) s 30 · s 51(3)(c) · s 19
   结论  入住时已有污渍，房东不得就此扣款
```

**③ 输出逐项结论、申诉信和行动路线**
一屏看到被扣多少、多少可争议、为什么、接下来做什么；申诉信可编辑、可下载 PDF、可复制全文；行动路线图给出 Fair Trading / Consumer Affairs → NCAT / VCAT 的完整路径、费用与时限。

## 为什么可信

- **诚实评估**：不是所有扣款都能争。房东占理的项目（比如拖欠租金抵扣、未付水费），AI 会直接告诉你「合法，别争」——不给你虚假希望
- **不下没把握的结论**：当合同里看不到某项义务时，AI 不会断言「合同没有」（毕竟只读了你上传的那几页），而是给出 ⚠️ 并援引 **s 165** 要求房东在 7 日内出示条款与发票——**举证责任本来就在房东**
- **引用可校验**：AI 引用的每条证据必须真实来自你上传的材料，每条法条必须在注入的官方法条白名单内；对不上的引用会被服务端丢弃，该项自动降级为「待核实」
- **法条来自官方**：NSW Fair Trading、Consumer Affairs Victoria、RTBA、NCAT/VCAT 与州立法数据库，逐条核实、附原文引用与来源链接
- **不收集你的数据**：无需注册登录，没有数据库，分析在会话内完成即走

## 技术栈

- Next.js（App Router）+ TypeScript + Tailwind CSS v4，部署于 Vercel
- **三段式 OpenAI 管线**：轻量模型做字段预填 → 强模型读证据出结构化事实 → 强模型对照法条出逐项结论；分析中的进度是**真实的两段**，不是假动画
- 州法规以结构化数据直接注入上下文（不建向量库），保证引用稳定准确
- 无数据库、无登录；PDF 与分享图卡均在前端生成
