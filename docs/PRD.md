## 2. 产品定位

- **名称**：BondBack · 押金侠
- **一句话简介**：押金被房东乱扣？拍照上传证据，AI 对照州租赁法逐项审查，30 秒生成一封让房东以为你请了律师的维权信。
- **核心场景**：退租押金维权
- **产品形态**：「报税式」结构化向导流水线。**明确不做 chatbot 对话形态。**
- **州覆盖**：NSW + VIC（法条/机构/费用因州而异）；其余州在下拉框中显示但标「即将支持」
- **语言**：界面全中文；维权信正文英文 + 中文对照解释

### 纠纷类型（预设 5 类 + 兜底）

| # | 类型 | 说明 |
|---|------|------|
| 1 | 清洁费 | |
| 2 | 损坏 vs 合理磨损（fair wear and tear） | |
| 3 | 提前解约扣费 | |
| 4 | 押金逾期未退 / 未存管 | |
| 5 | 拖欠租金抵扣 | 房东通常占理，AI 必须诚实判「合法别争」——这是可信度卖点 |
| 6 | 其他 | 兜底 |

一次退租常涉及多笔扣款，胜算评估须**逐项**给结论（见 §3.5）。

## 3. 用户流程（形态 C：结构化向导骨架 + 自动预填魔法）

### 3.1 首页双入口

- 「😤 我的押金被扣了」→ 真实流程（§3.2 起）
- 「👀 先看个案例」→ 预制静态示例（§4），默认体验路径
- [条件解锁] 第三入口「📸 我刚搬进来，先留证据」→ 入住留证模式（§6）

### 3.2 三步向导

1. **选州**：NSW / VIC 可选；其余州显示但标「即将支持」
2. **纠纷类型**：见 §2 表格
3. **关键数字**：押金金额 / 被扣金额 / 退租日期

**「隐藏武器扫描」问题**（向导内必问）：

> 你收到过州政府押金存管确认邮件吗？（VIC = RTBA / NSW = RBO）

选「没有 / 不确定」→ 胜算评估卡亮**红色警报**：「押金可能未合法存管，此为违法行为，是你最强谈判筹码」，并写进维权信。这是视频里单独给 15 秒的高光时刻。

### 3.3 证据上传与自动预填

- 支持：房间照片 / lease PDF / 入住 condition report / 与房东聊天截图
- **gpt-4o-mini 自动提取预填字段**（押金金额、地址等）——上传后表单字段自动填好，是演示的「魔法时刻」之一
- 识别失败 → 静默回退手填，**永不翻车**（不阻塞流程、不弹吓人的报错）
- 证据可跳过；信息越全，评估越准

### 3.4 AI 分析

- 强模型后台分析；UI 为**进度动画，非聊天气泡**
- 分析逻辑三板斧：
  1. 损伤是否**原已存在**（对照入住 condition report）
  2. 合同是否**真有此义务**
  3. 是否属 **fair wear and tear**

### 3.5 输出三件套（截图/视频高光）

1. **胜算评估卡**：逐项扣款 ✅合法 / ❌不合法 / ⚠️存疑 + 具体法条编号
2. **正式英文维权信**：可编辑、可下载 PDF；附中文对照解释
3. **行动路线图（战术手册）**：
   - Fair Trading（NSW）/ Consumer Affairs（VIC）→ NCAT / VCAT 升级路径、费用、时限
   - 邮件留证话术模板（如「正如我们电话中沟通的…」）
   - 抢先向 RTBA / RBO 发起 claim 的程序指引

### 3.6 战报卡

结果页附可保存分享的图卡（如「AI 帮我追回 $1,120」）+ 产品二维码——**分享即拉票**。

## 4. 预制示例案例（默认体验路径）

- **静态预生成、零 API 调用**；文案逐字手工打磨
- 按真实小红书案例改编：押金 $3,560、被索扣 ~$800
- 三笔扣款三种反杀 + 一笔诚实判「合法别争」：

| 扣款项 | 结论 | 反杀依据 |
|--------|------|----------|
| 地毯污渍 | ❌ 不合法 | 入住报告已标注原有损耗 |
| 草坪维护 | ❌ 不合法 | 合同无此义务 |
| 墙面钉眼 | ❌ 不合法 | 房东原有痕迹 + 合理磨损 |
| （一笔） | ✅ 合法，别争 | 展示 AI 的诚实与可信度 |

- 示例页脚注明：「这是预载示例，你的案子会实时分析」

## 5. 非功能需求

- **移动优先**响应式单页应用（链接在微信群传播，绝大多数人手机打开）；桌面端可用即可
- **无登录、无数据库**：会话内完成一切，不存储用户数据
- PDF 前端生成下载
- 简单限流防刷（API route 层）
- 页脚免责声明：「不构成法律意见」，必须在
- 报错兜底 + 加载动画：AI 调用失败要有体面的降级提示
- 成本预算：整场比赛 API 花费 $10-30 AUD

## 6. 条件解锁功能：入住留证模式

- **解锁条件（军规 2）**：仅当 7/25 晚主流程端到端跑通并部署后才动工
- 功能：拍照 → AI 生成带时间戳的 condition report PDF 存档（复用照片分析引擎）
- 入口：首页「📸 我刚搬进来，先留证据」
- **未解锁时的替代**：「愿景橱窗」——即将支持：QLD/WA、入住留证、中介往来助手

## 7. 技术方案（已确认，勿更换）

- Next.js（App Router, TypeScript, Tailwind CSS）+ Vercel 部署
- OpenAI 双模型分工：
  - **gpt-4o-mini**：字段提取 / 截图识别等脏活
  - **强模型（gpt-4o 或更新）**：胜算评估 + 维权信生成
  - API key 仅在服务端（API route），绝不进前端
- **法条不建向量库**：NSW/VIC 押金法规整理成结构化资料，按州直接塞 prompt 上下文（引用更稳定）
- 不换模型供应商（DeepSeek 视觉能力弱，照片分析是核心功能；机会成本分析已做过）

## 8. 法条资料需求（任务 2，最大翻车点 = 引用错法条）

**来源白名单**：Fair Trading NSW、Consumer Affairs Victoria、RTBA、
NCAT/VCAT、tenants.org.au、tenantsvic.org.au、NSW/VIC 州立法数据库。
其中法案名称、条款号与英文原文以州立法数据库为准；租客组织网站只作解释和交叉核对，
不能单独支撑已确认法条。

按州覆盖以下条目：

- 押金存管义务与期限、未存管罚则
- 退租后 claim 流程与双方时限
- 仲裁（NCAT/VCAT）申请费用
- "reasonably clean" 标准
- fair wear and tear 定义
- condition report 规则（3-7 天窗口）

**产出**：按州结构化、带原文引用与来源 URL 的资料文件；存疑条目显式标注，关键条款由用户抽查。**宁缺毋错。**

## 10. 提交物与视频方案（3 分钟，钩子 A 定稿）
