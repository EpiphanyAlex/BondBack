## 1. 首页

**首屏必须包含一张真实对照卡**——直接 import 03b 的对照卡组件，喂 04a 示例常量里的卡①。投票者不点任何东西就能看到「证据 → 合同 → 法条 → 结论」长什么样，这是对抗「看起来就是上传文件 → AI 写封信」的第一道防线。

```
房东乱扣 Bond？先别认栽。
上传扣款清单和入住报告，AI 按 NSW/VIC 租赁法规逐项比对证据，
告诉你哪几笔不应扣、凭哪条法规，并生成一封可直接发送的英文申诉信。

[😤 我的押金被扣了]   [👀 先看个案例]

───────── 以下是它的实际输出 ─────────
┌ 退租清洁 + 地毯蒸洗  $780      ❌ ┐
│ 证据  入住报告 P3："Carpet: existing stains"
│ 合同  笼统的专业洗地毯条款可能无效
└ 法条  RT Act 2010 (NSW) s 30 · s 51(3)(c)  ┘
```

往下滚：三格能力图示（① 读懂你的证据 ② 对照州法条 ③ 出结论 + 信 + 路线）→ **愿景橱窗**（即将支持：QLD/WA、入住留证、中介往来助手，措辞不得暗示当前可用）→ 页脚免责。

**桌面 ≥1024px**：hero 双栏（左标题+简介+双入口，右对照卡）。首屏对照卡在手机上可以只露出上半张，用于暗示往下滑。

## 2. `/sample` —— 零 API 全流程重放

**不是静态结果页，是把整个过程播一遍。** 投票者看到的是**过程**而不只是结果；同时这是演示视频的零 API 风险素材源。

数据全部来自 04a 的常量，**零网络请求**，断网可看。

### 重放时轴（节拍用 `--duration-beat`）

| 时间 | 画面 |
|---|---|
| 0.0s | 入住报告.pdf 飞入 |
| 1.2s | 租约.pdf 飞入 |
| 2.4s | 聊天截图.png 飞入 |
| 3.6s | 扣款清单.jpg 飞入 |
| 4.5s | 押金 $3,560 / 被扣 $1,306 / 扣款 3 项 —— 字段逐个自动填入（金色扫过，复用 `.prefilled`） |
| 6.0s | 「正在阅读入住报告…」→ 读到 3 条 |
| 7.5s | 「正在阅读租约与聊天记录…」→ 读到 4 条 |
| 9.0s | 「对照 NSW 租赁法 5 条法条…」 |
| 11s | 三张对照卡逐张翻开 → 停在完整结果页 |

- 全程约 12 秒，**右上角常驻「跳过」**，任何时刻可点，直达结果页
- 重放结束后的页面**就是** 03b 的结果页（同组件、同数据），与真实流程视觉完全一致
- 遵守 `prefers-reduced-motion`：开启时直接呈现结果页，不播动画
- 页脚注明：「这是预载示例，你的案子会实时分析」

## 3. 战报卡

```
┌──────────────────────────────┐
│ 【示例案例】     BondBack · 押金侠 │
│                              │
│   AI 逐项找出                  │
│   $1,120 可争议扣款            │
│   按此应退回至少 $3,374         │
│                              │
│ 押金 $3,560 · 索扣 $1,306      │
│ 3 笔 · NSW 租赁法 5 条法条      │
│                      █░█ 二维码 │
└──────────────────────────────┘
```

- **措辞纪律（红线）**：不得写「帮我追回」「拿回」——除非确实已追回。工具的战果是**找出可争议扣款**
- 不用第一人称（避免用户转发时替一个虚构案例作证）
- 示例页的卡带「示例案例」角标；真实结果页的卡不带
- 主数字用 `text-title`/`text-hero` + `--color-amount-hero`，**必须在深色面上**（浅底对比度不足）
- 实现：`html-to-image` DOM→PNG 渲成 `<img>`（微信内长按即可保存）+ `qrcode` 指向部署 URL
- 卡片尺寸按微信分享友好比例（建议 3:4 竖版）

## 4. 验收标准

- [ ] 首页手机首屏能同时看到：标题、简介、双入口、**一张真实对照卡**
- [ ] 首页对照卡与结果页的对照卡是**同一个组件**（不得复制一份）
- [ ] `/sample` 重放全程零网络请求、断网可看、首屏 < 1s
- [ ] 「跳过」任何时刻可用，点后直达结果页
- [ ] `prefers-reduced-motion: reduce` 时不播动画，直接给结果
- [ ] 重放结束后的页面与 `/result` 视觉完全一致
- [ ] 战报卡在微信内长按可保存；二维码可扫且扫开是产品
- [ ] 战报卡文案不含「追回」「拿回」等已实现结果的表述
- [ ] 愿景橱窗措辞为「即将支持」，不暗示当前可用
- [ ] 桌面 ≥1024px：hero 双栏正常
- [ ] `pnpm check:tokens` 零违规
