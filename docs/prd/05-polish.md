# 05 · 打磨保险（任务 6）

> 母文档 §5。目标不是加功能，是**堵住演示与传播中的翻车口**。

## 清单

### 移动端 / 微信（传播主战场）

- [ ] 微信内置浏览器实测走全流程（iOS + Android 至少各一）
- [ ] **微信安卓深色模式实测**：`color-scheme: light` 生效，配色未被强制反色
- [ ] 微信链接卡片：OG meta（标题 = 一句话标题、描述 = 简介、缩略图）——链接在群里甩出来必须好看
- [ ] PDF 下载在微信内的兜底提示（「点右上角 → 浏览器打开」）+ 复制全文按钮可用
- [ ] iPhone Safari 底部工具栏不遮挡账本条主 CTA

### 响应式与视觉一致性

- [ ] **360px 宽度**：账本条不溢出、全站无横向滚动
- [ ] **≥1024px**：首页 hero 双栏、结果页/示例页双栏且右栏 sticky 正常
- [ ] **`pnpm check:tokens` 零违规**（任意字号、禁用断点、硬编码 hex、行内 ms）
- [ ] 三档结论在任何页面都同时有图标 + 颜色 + 中文标签（不只靠颜色）

### 防刷与成本

- [ ] `/api/*` 简单限流：按 IP 内存计数（serverless 尽力而为即可）+ 单次请求体积上限
- [ ] `AI_ENABLED=false` 全局开关实测：一键只留示例模式，`/sample` 不受影响
- [ ] 图片上传前客户端压缩（控 token 成本与请求体积）

### 兜底与观感

- [ ] AI 调用失败/超时 → 体面降级文案 + 重试；绝不白屏
- [ ] **两段真实进度动画顺滑**，中途失败时能指出失败在哪一段并可单独重试
- [ ] 免责声明全站在；对外文案通读一遍，去掉绝对化承诺（「帮你拿回」→ 辅助定位；战报卡不得写「追回」）
- [ ] API route `maxDuration` 配置到位，杜绝平台默认超时截断
- [ ] 示例页所有人名/地址/机构名确认为虚构

## 验收标准

以上清单全勾。此模块完成 = 具备封版资格。
