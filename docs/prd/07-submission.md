## 视频分镜（竖屏手机框录屏 + 中文配音 + 中英字幕，不出镜）

**编排原则：主体时间按三层 AI 能力分配，第二层拿走最大一块。**

| 时间 | 内容 |
|------|------|
| 0:00-0:10 | 黑屏问句：「在澳洲租过房的人，谁没被扣过押金？」→「BondBack 押金侠——用 AI 和你所在州的法律，逐项找出不该扣的钱。」（**不特指悉尼**，覆盖 NSW+VIC） |
| 0:10-0:40 | **第一层**：上传 4 份证据 → 字段自动填好（金色扫过特写）→ **真实进度**「正在阅读你的入住报告…读到 7 条事实」 |
| 0:40-1:40 | **第二层（核心高光，占全片最大篇幅）**：三张对照卡逐张特写。镜头在卡①的 `"Carpet: existing stains noted"` 这句英文引语上停住，再点一下滚动高亮到入住报告原件的那一行 |
| 1:40-2:05 | **第三层**：英文申诉信（可编辑、可下载）+ 行动路线图 |
| 2:05-2:20 | 押金存管黄卡 +「当场去 RBO 查押金号」的动作 |
| 2:20-2:50 | 战报卡（$1,120 可争议 / 应退至少 $3,374）+ 愿景橱窗 + 投票 CTA |

**结尾不使用「全额退还」聊天截图**：为视频造截图等于在提交作品里放伪造证据；用他人原案例的截图则是拿别人的隐私材料给自己作证。两者都与本产品的诚实性卖点直接冲突，也正是外部评审点名的可信度问题。

### 录真实流程前必读（2026-07-25 端到端实测得到的两条）

1. **租约页必须进管线，否则卡① 的 ❌ 出不来。** 只给入住报告 + 扣款清单时，清洁那笔会判 **⚠️** 并说明「如果房东依赖笼统的专业地毯清洗条款，该条款还可能受限」——这是证据驱动的**正确**行为（没看到条款就不能断言条款无效），不是 bug。但全片高光那一帧要的是 ❌ + s 19，所以录制用的四份证据一份都不能少。

2. **「读到 7 条事实」这个数字只属于 `/sample`。** 7 条是 04a 手工打磨的示例常量；真实流程读同样四份材料会读出 20 条上下（实测 21 条），数量随材料清晰度浮动。配音稿若要报数，要么固定用 `/sample` 素材，要么把这句改成不报数的说法。

主素材用 `/sample` 就同时避开这两个坑——它零 API、断网可看、且视觉与真实结果页完全一致。
