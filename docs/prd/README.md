## 封版前最后一轮（2026-07-26 手测返工，PR #13）

四个视觉问题，其中三个底下压着功能 bug；顺着控制台报错又挖出第四个。**这些都发生在各模块 PRD 验收之后，所以记在这里而不是各自的模块文件里。**

| 症状 | 底下真正的问题 |
|---|---|
| 首页顶栏两个链接点不动 | 侠客图在 `lg` 上从右下角放大到 125%，盒子溢出格子盖住顶栏，透明像素照吃点击。图加 `pointer-events-none`、顶栏抬 `z-10` |
| 第 2 幕「只能看到 01 的输出」 | 朱红顶线**永远**画在 01 上，被读成「你正在看 01」。红色改成表示「当前」，三段做成标签页，各自展示真实产物（原句 / 三轴 / 对照卡），默认自动轮播 |
| 核对页白框又挤又乱 | `prefill-sweep` 收在 `background-color: var(--card)` 且 `fill-mode: both` —— 每个被预填的字段永久留下一个无内边距白框。改为收在 `transparent`，金光换成不占布局的外扩阴影。同一条规则也在重放的深色面上留了白框、白底浅字 |
| 上传页 hover 不明显 | 「拖进来」是句假话：整个组件没有任何 drag 事件，拖进 PDF 会把页面顶掉——**而本产品无登录无数据库，向导填的一切只活在内存里**。补了真拖放，并在这一步在场期间吞掉落点之外的拖放 |
| 控制台 `SecurityError: cssRules` | `html-to-image` 遍历 `document.styleSheets` 撞上跨源的 Google Fonts 表。改为预先算好 `fontEmbedCSS` 交给它。量这条路时发现它在嵌**全部 429 条 `@font-face`——426 个 woff2、17.4 MB**，只为截一张分享卡，而用户都在微信里用移动数据。只嵌自托管拉丁字体后是 18 个文件、134 KB |

顺带的取舍，理由都写在代码注释里：`NSW · VIC` 从顶栏整条删掉（是能力不是去处）；重放三张卡由 500ms 一张改成 1200ms 一张（原来前两张肉眼看不见）并加了 2s 判决落幕；重放的暂停/重放两个控制删掉，只留「跳过」并移到顶栏右上角。
